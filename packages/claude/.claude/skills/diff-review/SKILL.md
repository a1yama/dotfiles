## これは何か

`claude-diff` CLI を使い、編集差分をブラウザの差分ビューアで表示する。ユーザーは行単位でコメントを残し、Claude はそのコメントをバックグラウンド監視で自動的に拾って対応する。IDE を開く必要も、Claude を中断する必要もない。

ビューアと監視はリポジトリを汚さない（フィードバックは `~/.local/state/claude-diff/<repo-hash>/` に保存）。

## 使い方

### 1. ビューアを起動する（バックグラウンド）

`run_in_background: true` で起動し、ブラウザを開く:

```bash
claude-diff serve
```

ポート競合時は `claude-diff serve --port 4600` のように変更する。デフォルトは 4517。

起動後、ユーザーに「ブラウザ (http://127.0.0.1:4517/) で差分を確認し、気になる行の `+` からコメントを残してください。終わったら右上の **レビュー完了** を押してください」と伝える。

- ブラウザ上部のセレクタで **未コミット差分 / ブランチ全体** を切替できる。任意のコミット範囲（例 `HEAD~3`, `a..b`）はテキスト欄に入力。
- 各行ホバーで出る `+` を押すとコメント入力欄が開く。
- 右上の **レビュー完了** ボタンがセッションの終了シグナル。押すとサーバが自ら停止し、`watch` にも伝わる。

### ブラウザ画面でできること

**ファイルツリー（左サイドバー）**

- 変更ファイルを GitHub と同じディレクトリツリーで表示する。ファイル名クリックでその差分へスクロールする。
- 各行に `+追加 -削除` 行数、未対応コメントがあるファイルには件数バッジが付く。
- ディレクトリ名クリックで折り畳む。中身が1つしかない階層は `a/b/c` と連結して縦を節約する。
- ヘッダー左の `☰` で表示/非表示。右端をドラッグすると幅を変えられる。

**Markdown プレビュー**

- `.md` / `.markdown` / `.mdown` / `.mkd` のファイルヘッダーに `差分 | プレビュー` タブが出る。
- プレビューは**差分の新しい側**を描画する（未コミット差分なら作業ツリー、`a..b` なら `b`）。画面の diff と食い違わない。
- レンダラは外部依存なしの自前実装。見出し / 段落 / リスト（ネスト・チェックボックス）/ 表 / コードブロック / 引用 / 水平線 / リンク / 強調 に対応する。
- **プレビュー中は行コメントを付けられない。** コメントを残すときは `差分` タブに戻る。

### 2. フィードバックを自動で拾う（重要）

サーバ起動後、`run_in_background: true` で監視コマンドを起動する:

```bash
claude-diff watch
```

これはコメントが入るかレビューが終わるまでブロックする。どちらかが起きるとコマンドが終了し、ハーネスが Claude を再起動する。**待機中はトークンを消費しない。**

`watch` の終了パターンは3つ。出力の先頭で見分ける:

| 出力 | 意味 | Claude がすること |
|---|---|---|
| `=== 新しいフィードバック N件 ===` | 行コメントが届いた | 修正 → `resolve` → **watch を再起動** |
| `=== DONE: レビュー終了 ===` | レビュー終了（サーバは停止済み） | **watch を再起動しない**。残 pending があれば対応してから報告 |
| `TIMEOUT:` | 既定30分、何も起きなかった | ユーザーに一声かけるか監視を再開 |

コメントが返ってきたときの手順:

1. コメント内容（`[id] file:line` 形式）に従って修正する。
2. 対応したコメントを `claude-diff resolve <id> [<id>...]` で resolved にする（ブラウザ上のバッジが緑になる）。
3. 再び `claude-diff watch` をバックグラウンド起動して次のコメントを待つ。

### 3. 終了

**ユーザーがブラウザの「レビュー完了」を押すのが正式な終了合図。** これで:

- サーバ (`serve`) が自分で停止する
- `watch` が `=== DONE: レビュー終了 ===` と未対応件数を出して終了する

つまり**プロセスは残らない**。`DONE` を受け取ったら watch を再起動せず、未 resolved のコメントが残っていれば対応してからレビュー完了を報告する。

ボタンを押さずにブラウザを閉じられた場合の保険として、**無操作が30分続くとサーバは自動停止**する（`serve --idle-timeout SEC`、`0` で無効）。このときも `watch` は `DONE`（理由: idle）で終了する。

念のため終了後に `claude-diff status` で未 resolved が無いか確認するとよい。

## 軽量モード（tmux）

ブラウザを使わず、別 tmux ペインに色付き差分を定期更新表示するだけでよい場合:

```bash
claude-diff tmux              # 未コミット差分を別ペインに表示
claude-diff tmux --range branch
```

`delta` が入っていれば自動で使う（なければ `less -R`）。この場合フィードバックはブラウザ経由ではないため、ユーザーは口頭/プロンプトで指示する。

## サブコマンド一覧

| コマンド | 説明 |
|---|---|
| `claude-diff serve [--port N] [--no-open] [--idle-timeout S]` | 差分ビューアを起動（完了/無操作で自動停止） |
| `claude-diff watch [--timeout S] [--interval S]` | 新規コメント or レビュー終了までブロック |
| `claude-diff resolve <id...>` | コメントを resolved に（`all` で全件） |
| `claude-diff status` | pending/delivered/resolved の件数と一覧 |
| `claude-diff tmux [--range R]` | tmux ペインに色付き差分を定期表示 |
